Know which pull requests
deserve your time.

Scores your PR queue before you open a single diff. What to review, what to skip, what needs author follow-up — in seconds.

# Install once
$ pip install git+https://github.com/JackSpiece/maintainer-radar.git@v0.20.0

# Run on any repo
$ maintainer-radar recommend https://github.com/owner/repo/pulls

# Or scaffold a scheduled report
maintainer-radar init-repo --profile balanced

🔒

Truly read-only

Never posts, comments, or writes anything. There is no hosted service or model token.

⚡

One command away

Works through the GitHub CLI you already have. No new accounts, no dashboards to configure.

🔍

Transparent scoring

Every score shows its heuristic breakdown. No hidden model — just rules you can read and tune per project.

📅

Session planning

Builds a time-boxed review plan to recommend the next maintainer session. Know what fits before opening anything.

Deeper scans from your terminal

The CLI gives you hydrated scans, offline JSON analysis, review plans, and output in Markdown, JSON, CSV, or HTML — all without posting a single comment.
